# Chapter 10 — Printing and Copying

## What This Folder Contains
How to print, preview, and copy SWMM output (maps, graphs, reports, tables) to printers, the Windows clipboard, or files.

## Files

| File | Description |
|------|-------------|
| `10.1_Selecting_a_Printer.md` | Select from installed Windows printers and configure printer properties via File > Page Setup > Print Setup dialog. |
| `10.2_Setting_the_Page_Format.md` | Page Setup dialog: paper orientation (Portrait/Landscape), margin settings (left/right/top/bottom), header/footer configuration with alignment and page numbering. |
| `10.3_Print_Preview.md` | File > Print Preview: shows each page's appearance. Left mouse = zoom in; right mouse = zoom out/pan. |
| `10.4_Printing_the_Current_View.md` | Print any active SWMM window via File > Print or toolbar: Study Area Map, Status Report, Summary Report, Time Series/Profile/Scatter Graphs, Tabular Reports, Statistical Reports. |
| `10.5_Copying_to_Clipboard_or_File.md` | Copy workspace contents via Edit > Copy To: three formats — Bitmap (pixel graphics), Metafile (vector, best for documents), Data (text/spreadsheet). Copy to Windows clipboard or file. Select table cells before copying for partial table export. |

## Key Terms & Concepts
- **Print formats**: Portrait, Landscape
- **Copy formats**: Bitmap (raster), Metafile (EMF vector), Data (tab-delimited text)
- **Printable views**: Map, Status Report, Summary Report, all graph types, Tabular Report, Statistical Report
- **Copy destination**: Windows clipboard or file
- **Header/footer**: custom text with alignment (left/center/right) and page number option
- **Table copy**: select specific cells first for partial copy; or copy entire table
