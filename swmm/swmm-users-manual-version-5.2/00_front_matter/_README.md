# Front Matter — Overview & Preliminary Documentation

## What This Folder Contains
Introductory and legal documents that frame the SWMM 5.2 User's Manual: an abstract summarizing the software, an EPA disclaimer, an institutional forward, and acknowledgements including the full table of contents.

## Files

| File | Description |
|------|-------------|
| `00_abstract_Abstract.md` | Executive summary of SWMM as a dynamic rainfall-runoff simulation model for urban drainage. Describes capabilities: quantity/quality simulation, single-event and continuous modes, visualization outputs. |
| `00_disclaimer_Disclaimer.md` | EPA legal disclaimer: peer-review status, warranty limitations, trade name policy. No liability for use of software or document. |
| `00_forward_Forward.md` | EPA/CESER institutional statement on SWMM's global role in stormwater, sewer, and drainage planning; gray and green/gray hybrid stormwater control. |
| `00_acknowledgements_Acknowledgements.md` | Authors (Lewis Rossman, Michelle Simon, USEPA), reviewers (Innovyze, CDM Smith, CHI). Contains the **complete table of contents** for the entire 12-chapter manual + 5 appendices. |

## Key Terms & Concepts
- Dynamic rainfall-runoff simulation
- Single-event vs. continuous simulation
- Urban stormwater management
- Runoff quantity and quality
- Gray infrastructure, green infrastructure, hybrid stormwater control
- CESER (EPA's Center for Environmental Solutions and Emergency Response)
