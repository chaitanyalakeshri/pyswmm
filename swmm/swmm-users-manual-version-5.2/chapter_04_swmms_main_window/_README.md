# Chapter 4 — SWMM's Main Window

## What This Folder Contains
Complete reference for the SWMM graphical user interface: main window layout, all menu commands, keyboard shortcuts, toolbars, status bar indicators, the Study Area Map, Project Browser, Map Browser, Property Editor, and program preferences.

## Files

| File | Description |
|------|-------------|
| `4.1_Overview.md` | Main window layout: Main Menu, Main Toolbar, Status Bar, Study Area Map with Map Toolbar, Browser panel (Project/Map Browser), Property Editor. |
| `4.2_Main_Menu.md` | All 8 menu categories with 40+ commands: File, Edit, View, Project, Report, Tools, Window, Help. |
| `4.3_Keyboard_Shortcuts.md` | 20+ keyboard shortcuts: Ctrl-N (New), Ctrl-O (Open), Ctrl-S (Save), F9 (Run), Ctrl-G (Graph), Ctrl-Q (Query), Ctrl-F (Find), F2 (Edit), etc. |
| `4.4_Toolbars.md` | Main Toolbar (13 buttons: file/edit/view/report) and Map Toolbar (20+ buttons: object selection, navigation, add rain gage/subcatchment/nodes/links). |
| `4.5_Status_Bar.md` | Six status bar sections: Auto-Length toggle, Offsets display mode, Flow Units selector, Run Status indicator, Zoom Level, XY Location coordinates. |
| `4.6_Study_Area_Map.md` | The map workspace: color-coded properties, backdrop support, zoom/pan, object sizing, flow direction arrows, symbol display, export. |
| `4.7_Project_Browser.md` | Categorized object list with add/delete/edit/reorder/sort buttons; synchronized selection with the Study Area Map. |
| `4.8_Map_Browser.md` | Three panels: Themes (subcatchment/node/link color coding), Time Period (date/time/elapsed selection), Animator (playback controls with speed adjustment). |
| `4.9_Property_Editor.md` | Two-column grid for editing object properties; resizable columns, hint area, text/dropdown/ellipsis input types, keyboard navigation, page up/down object cycling. |
| `4.10_Setting_Program_Preferences.md` | Preferences dialog: General tab (blinking highlighter, flyover labeling, confirm deletions, auto backup, tab-delimited file, elapsed time, save results prompt, welcome screen, style theme), Numerical Precision tab (decimal places for subcatchment/node/link results). |

## Key Terms & Concepts
- **Panels**: Study Area Map, Project Browser, Map Browser, Property Editor
- **Menus**: File, Edit, View, Project, Report, Tools, Window, Help
- **Map Toolbar objects**: Rain Gage, Subcatchment, Junction, Outfall, Flow Divider, Storage Unit, Conduit, Pump, Orifice, Weir, Outlet, Text Label
- **Status Bar**: Auto-Length, Offsets mode, Flow Units, Run Status (green ✓ / red ✗), Zoom Level, XY Coordinates
- **Map Browser Themes**: Color-code map by any simulated parameter
- **Map Browser Animator**: Play temporal results as animation
- **Preferences**: Style themes, numerical precision, backup behavior
